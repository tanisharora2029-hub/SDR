# India location directory

The India extract in `india-cities.json` is adapted from the [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database/tree/76a6e1a60eaea25fad54710b0981b461c0629c2c) by the project and its contributors. The extract retains state names and city IDs, names and coordinates, sorted within each state. The adapted database is available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Two whole-degree coordinate pairs were refined using uniquely matching Indian populated places in the [GeoNames cities500 gazetteer](https://www.geonames.org/), available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
